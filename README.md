# Bootstrap-Camp

Small Bootstrap practice projects I made while learning. Each HTML file is one example.

## What's inside

- **bootstrap-card.html** - A single card with a photo, a badge, a short text and a button. It has a small hover lift effect.
- **dashboard-template.html** - A simple admin dashboard page. Dark sidebar with icons, a top navbar with a dropdown, three stat cards and a recent activity table. The sidebar collapses on mobile.
- **bootstrap-carousel.html** - An image slider with three slides, captions, dots and prev/next arrows. It auto-plays.
- **bootstrap-hero-section.html** - A dark hero section with a big heading, short text, two buttons and an image next to the text.
- **one-paged.html** - A full one-page site: fixed navbar with a collapse button on mobile, hero, about, services and contact form sections, plus a footer.
- **assets/** - Bootstrap CSS, Bootstrap JS and Bootstrap Icons files saved locally, so the pages work even without internet.

## Tech stack

- Bootstrap 5.3.2 (CSS and JS bundle, saved in `assets/`)
- Bootstrap Icons 1.11.3 (used in the dashboard sidebar, saved in `assets/`)
- Plain HTML and a little CSS in `<style>` tags
- No build tools, no npm, no frameworks

## How to view

1. Download or clone this repo.
2. Open any `.html` file in a browser. For example double-click `one-paged.html`.
3. No server needed. The Bootstrap files are already in the `assets/` folder.

Note: the photos in the card, carousel and hero examples load from the internet, so you need to be online to see those images. Everything else works offline.
